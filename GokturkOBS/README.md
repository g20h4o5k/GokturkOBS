# GöktürkOBS

Akbim OBS için geliştirilen, macOS'a özel, native SwiftUI istemcisi.

GöktürkOBS'nin amacı Akbim OBS'nin web arayüzü yerine daha hızlı, sade ve macOS ile uyumlu bir kullanım deneyimi sunmaktır.

## Gereksinimler

- macOS 26 veya üzeri
- Apple Silicon
- Swift 6+

## Uyarı

GöktürkOBS resmi bir Akbim uygulaması değildir ve Akbim ile bağlantılı veya Akbim tarafından onaylanmış değildir.

Proje şu anda kişisel kullanım ve geliştirme amacıyla oluşturulmaktadır.
